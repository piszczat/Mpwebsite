# MarcinP Portfolio

Interactive Microsoft Dynamics 365 Finance & Operations developer portfolio, designed as a compact Visual Studio / D365 Application Explorer workspace.

## Highlights

- D365-style Application Object Tree (AOT)
- Interactive X++, JSON, configuration and Markdown documents
- Sanitised F&O case studies
- Simulated build and Output window
- Command Palette with keyboard shortcuts
- Responsive desktop and mobile layouts
- Direct email and LinkedIn contact links

## Stack

- Next.js / React
- TypeScript
- Vinext / Vite
- Tailwind CSS
- Radix UI primitives
- Lucide icons

## Local development

```bash
npm ci
npm run dev
```

Production build:

```bash
npm run build
```
